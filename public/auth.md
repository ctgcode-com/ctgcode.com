# Authenticating with CTG Code

CTG Code (https://ctgcode.com) is a public, static website. **No authentication is required.**

- No API keys, OAuth tokens, cookies, or logins are needed to access any public page, its content, or the sitemaps.
- All content is served over HTTPS and is freely readable by browsers, search crawlers, and AI agents.
- There is no private or gated area, and there is no interactive API or agent endpoint to authenticate against.

To discover the site's content, use the sitemap index at
https://ctgcode.com/sitemap-index.xml
